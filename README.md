# Fee Calculator App

A responsive frontend web application that calculates total fees dynamically based on user input. Built using HTML, CSS, Bootstrap, and JavaScript.

## 🚀 Features
- User-friendly input form
- Dynamic fee calculation
- Real-time result display
- Responsive design (mobile-friendly)
- Clean and interactive UI

## 🛠️ Technologies Used
- HTML
- CSS
- Bootstrap
- JavaScript

## 💡 How It Works
- User enters fee details (e.g., course name)
- Application processes input using JavaScript
- Total fee is calculated and displayed instantly

## 🎯 Key Concepts Used
- DOM Manipulation
- Event Handling
- Form Validation
- Responsive Web Design

## 📂 Project Structure
- index.html
- style.css
- script.js
